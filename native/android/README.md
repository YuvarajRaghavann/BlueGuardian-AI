# Native Android code

Java code that does what only Android can. At build time [`scripts/prepare-capacitor-ci.mjs`](../../scripts/prepare-capacitor-ci.mjs) copies these files into the Capacitor-generated Android project (package `com.blueguardian.hybrid`) and registers permissions and the receiver.

| File | JavaScript name | What it does |
| --- | --- | --- |
| `BlueGuardianBluetoothPlugin.java` | `BlueGuardianBluetooth` | BLE scanning and classic discovery, paired list, scan permissions |
| `BlueGuardianDevicesPlugin.java` | `BlueGuardianDevices` | Paired + connected devices, pair and connect, live presence/bond events, deep check, Find it, location, share, maps |
| `BlueGuardianSecureLinkPlugin.java` | `BlueGuardianSecureLink` | Secure Share: BLE advertising, L2CAP channel, framing, Android Keystore wrapping, file quarantine |
| `BlueGuardianPresenceReceiver.java` | — (manifest receiver) | Records connect/disconnect times and places, even when the app is closed |
| `MainActivity.java` | — | Registers the plugins with Capacitor |
| `res/` | — | Launcher icons (legacy, round, adaptive) and splash image, generated by [`branding/render_icons.py`](../../branding/render_icons.py) |

The JavaScript side of each plugin lives in [`src/services/`](../../src/services): `nativeBluetoothService.ts`, `myDevices.ts` and `secureLinkNative.ts`.
